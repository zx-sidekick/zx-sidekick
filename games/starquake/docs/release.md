**You need your own copy of Starquake to play.** ZX Sidekick contains no part of the original game: it runs your tape, unchanged. README.txt in the archive says where to find one. Not affiliated with or endorsed by the rights holders.

Run the program and it asks for the tape, or put `starquake.tap` in the same folder first. You can also give the tape on the command line: `./zx-sidekick-starquake path/to/starquake.tap`, or `zx-sidekick-starquake.exe path\to\starquake.tap` on Windows.

**macOS:** the binary is not signed, so macOS blocks it the first time you run it. In Terminal, in the folder you extracted, run `xattr -d com.apple.quarantine zx-sidekick-starquake`. Or try to open it once, then allow it under System Settings, Privacy & Security.

**Gamepads** are the Kempston joystick: choose 1 on the title screen. The guidance shows the letters of the pad you have: Xbox, Switch or PlayStation.

`THIRD-PARTY.txt` in the archive lists the libraries built into the program and their licences.
