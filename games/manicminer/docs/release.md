**You need your own copy of Manic Miner to play,** the original Bug-Byte release. ZX Sidekick contains no part of the original game: it runs your tape, unchanged. README.txt in the archive says where to find one. Not affiliated with or endorsed by the rights holders.

Run the program and it asks for the tape, or put `manicminer.tap` in the same folder first. You can also give the tape on the command line: `./zx-sidekick-manicminer path/to/manicminer.tap`, or `zx-sidekick-manicminer.exe path\to\manicminer.tap` on Windows.

The game's text is in the Spectrum's own letters: the program includes the ROM's character set, and nothing else from a ROM. Amstrad have kindly given their permission for the redistribution of their copyrighted material but retain that copyright.

**macOS:** the binary is not signed, so macOS blocks it the first time you run it. In Terminal, in the folder you extracted, run `xattr -d com.apple.quarantine zx-sidekick-manicminer`. Or try to open it once, then allow it under System Settings, Privacy & Security.

**Gamepads** and the arrow keys are the Kempston joystick, which the game finds by itself: move, and the bottom or left face button to jump (A or X on an Xbox pad). Start pauses, and starts a game on the title screen.

`THIRD-PARTY.txt` in the archive lists the libraries built into the program and their licences.
