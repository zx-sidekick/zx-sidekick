# assets

Local files the program or its checks need but the repository must never hold: tapes, snapshots, recordings, and third-party test files whose licences forbid committing them. Everything here except this README is ignored by git, and the repo guard in CI fails on any `.tap`, `.tzx`, `.z80`, `.sna`, `.szx` or `.rom` committed anywhere.

For Starquake: download `Starquake.tap.zip` from World of Spectrum (worldofspectrum.net/item/0004873) and put it here, or locate it from the program's tape prompt.
